## 🚀 Development Workflow

We use **GitHub** to collaborate efficiently and maintain code quality.

### 🔀 Pull Requests (PRs)

* All changes must go through a **Pull Request**.
* PRs are used to review each other's code before merging.
* There is a **PR template** that must be filled in when creating a PR.

  * This ensures everyone understands what changes were made.
  * It also makes reviewing easier and faster.

### ✅ Code Reviews

* Each PR must be approved by **at least 2 people**.
* Reviews are expected to be **critical and constructive**

## 🤖 Automation & CI/CD

We have automated workflows set up to streamline development:

## 🚢 Deployment

### Production Deployment (PRD)

* Deployment to production requires approval from:

  * **@xpvanderhoek**
* If you want to deploy:

  * Tag **@xpvanderhoek** in Discord.

### Manual Deployment

You can also trigger a deployment yourself:

1. Go to the **Actions** tab in GitHub.
2. Select: **Build & Deploy Godot Game**
3. Click **Run workflow**
4. Choose the desired branch
5. Start the workflow
